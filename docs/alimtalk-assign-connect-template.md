# 알림톡 템플릿 — 배정 연결 인증코드 (등록용)

직무지도원 배정 파이프라인 §7. 기존 가입 직무지도원이 새 배정을 연결할 때 받는 인증코드 알림톡.
코드(`app/api/worker/contracts/route.ts` → `sendConnectCodeExisting`)가 보내는 메시지와 **정확히 일치**하도록 등록해야 한다(Aligo는 치환된 message를 등록 템플릿과 매칭).

## 등록 정보
- **템플릿 코드(가칭)**: 등록 후 발급되는 코드를 `.env`의 `KAKAO_ASSIGN_CONNECT_TEMPLATE_CODE`에 설정
- **채널/발신프로필**: 기존 @able-link 동일
- **변수**: `#{name}`(직무지도원명), `#{code}`(6자리 인증코드)

## 템플릿 본문 (그대로 등록)
```
안녕하세요 #{name}님,

근로계약이 완료되어 새 현장 배정 연결이 필요합니다.
앱에서 아래 인증코드를 입력해 주세요.

인증코드: #{code}
(유효기간 7일)
```

## 버튼
- 유형: 웹링크(WL)
- 이름: `배정 연결하기`
- 모바일/PC URL: `https://able-link.co.kr/worker/connect`

## 강조표기(선택)
- 강조유형: 없음(또는 인증코드형). 인증코드형 사용 시 `#{code}`를 헤더 변수로.

## 등록 후 적용
1. 발급된 템플릿 코드를 운영/로컬 `.env`에 `KAKAO_ASSIGN_CONNECT_TEMPLATE_CODE=...` 추가
2. 미설정 시: 코드가 발송되지 않고 **앱 내 알림(WorkerNotice)으로 코드 전달**되는 폴백이 동작(거래 차질 없음). 따라서 등록은 비차단(non-blocking).
