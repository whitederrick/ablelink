# AbleLink 종합 테스트 시나리오 (2026-07-19)

모든 역할·플로를 **정상 / 경계 / 오류 / 권한 / 동시성 / 플랜** 축으로 점검하는 수동·E2E 시나리오.
각 케이스는 `전제 → 조작 → 기대결과` 형식. ⭐ 표시는 2026-07-19 세션 수정분 회귀 확인 대상.

## 0. 사전 준비

| 항목 | 값 |
|---|---|
| 시드 스크립트 | `npx tsx scripts/seed-all.mts` (admins 보존 wipe·3기관 대용량) |
| 운영자 | `admin` / `admin1234!` · (운영 실계정 `neverwhere`) |
| 위탁기관 담당자 | `manager01~03` / `Manager1234!` |
| 직무지도원 | 시드 워커 / `worker1234!` (loginId=전화번호) |
| 급여 참조 | `insurance_rates`·`income_tax_tables` 존재 필수(요율·세액표) |
| dev 서버 | 포트 3000, `npm run dev` |

> ⚠️ 운영 DB는 2026-07-19 초기화됨(`neverwhere` admin·급여참조·마이그만 잔존). 운영 재점검은 seed 또는 수동 셋업 후.

## 실행 순서 권고
1. seed → 로그인 3종(1장) → 계정·비번 UX(2장) — **UI 시각검증 필수**(비번모달·양식드롭다운·생년월일).
2. 배정→근태→문서→급여→연차→계약 순(데이터 의존).
3. 플랜게이트(5·9장)는 FREE/STARTER/STANDARD/PRO 각각.
4. 동시성(3-3·3-4·5-2·6-12·7-5)은 병렬 요청 스크립트로.
