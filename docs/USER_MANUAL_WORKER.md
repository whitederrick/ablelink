# Able-Link 사용자 매뉴얼 - 직무지도원

문서 버전: v0.9 draft  
대상 사용자: 직무지도원  
작성 기준: 2026-07-03 현재 코드 기준  
주의: 실제 화면명과 버튼명은 최종 배포본에서 일부 달라질 수 있습니다.

---

## 1. 이 매뉴얼의 목적

이 문서는 직무지도원이 Able-Link를 사용해 출근, 퇴근, 업무일지 작성, 문서 제출, 계약서 서명, 급여명세서 확인을 하는 방법을 설명합니다.

직무지도원의 기본 사용 흐름은 다음과 같습니다.

1. 로그인
2. 처음 로그인 시 온보딩 완료
3. 오늘 근무할 현장 확인 또는 선택
4. 출근 처리
5. 퇴근 처리
6. 훈련생별 업무일지 작성
7. 누락 일지 확인
8. 문서 생성 및 제출
9. 계약서 서명
10. 출근부 수정 요청 또는 휴무 요청
11. 급여명세서 확인
12. 프로필과 서명 관리

---

## 2. 로그인

### 2.1 접속 경로

- 로그인: `/worker/login`
- 로그인 후 홈: `/worker/home`

### 2.2 로그인 절차

1. Able-Link 직무지도원 로그인 화면으로 이동합니다.
2. 로그인 ID 또는 전화번호를 입력합니다.
3. 비밀번호를 입력합니다.
4. 로그인을 선택합니다.
5. 홈 화면으로 이동합니다.

### 2.3 로그인이 안 될 때

| 상황 | 확인할 것 |
|---|---|
| 비밀번호가 틀렸다고 나옴 | 대소문자, 숫자, 특수문자 확인 |
| 계정이 비활성이라고 나옴 | 소속 위탁기관 관리자에게 문의 |
| 임시 계정이라고 나옴 | 온보딩 화면에서 비밀번호 변경 필요 |
| 새 배정 연결이 안 됨 | 인증코드 또는 전화번호 확인 |

## 3. 처음 사용하는 경우

### 3.1 온보딩

경로:

- `/worker/onboarding`

온보딩이 필요한 경우:

- 임시 비밀번호로 처음 로그인한 경우
- 계약서 서명 후 새 계정이 만들어진 경우
- 관리자가 임시 계정을 발급한 경우

절차:

1. 이름과 전화번호를 확인합니다.
2. 사용할 비밀번호를 새로 입력합니다.
3. 약관과 개인정보 처리 내용을 확인합니다.
4. 저장합니다.
5. 홈 화면으로 이동합니다.

주의:

- 비밀번호는 다른 서비스와 다르게 설정하는 것이 좋습니다.
- 임시 비밀번호를 계속 사용하지 마세요.

### 3.2 기존 계정에 새 배정 연결

경로:

- `/worker/connect`

사용하는 경우:

- 이미 Able-Link 계정이 있는데 새 위탁기관/현장 배정을 받았을 때
- 알림톡으로 배정 연결 인증코드를 받은 경우

절차:

1. 배정 연결 화면으로 이동합니다.
2. 받은 인증코드를 입력합니다.
3. 연결을 완료합니다.
4. 홈에서 새 현장이 보이는지 확인합니다.

## 4. 오늘 근무할 현장 선택

### 4.1 현장 선택이 필요한 경우

다음과 같은 경우 현장 선택 화면이 나타날 수 있습니다.

- 한 명의 직무지도원이 여러 현장에 배정된 경우
- 오전과 오후에 다른 현장에서 근무하는 경우
- 새 현장 배정이 추가된 경우

경로:

- `/worker/select-site`

### 4.2 현장 선택 절차

1. 현장 선택 화면에서 오늘 근무할 현장을 확인합니다.
2. 현장명, 주소, 근무시간을 확인합니다.
3. 오늘 출근할 현장을 선택합니다.
4. 홈으로 이동합니다.

주의:

- 잘못된 현장을 선택하면 출근부, 일지, 문서가 잘못 연결될 수 있습니다.
- 오전/오후 현장이 다르면 근무 시간에 맞춰 현장을 전환해야 합니다.

| 누락 업무 | 작성해야 할 일지나 확인할 근태 |

## 6. 출근하기

### 6.1 출근 전 확인

출근 버튼을 누르기 전에 다음을 확인합니다.

- 오늘 현장이 맞는지
- 근무시간이 맞는지
- 휴대폰 위치 권한이 켜져 있는지
- 실제 현장 근처에 있는지

### 6.2 출근 절차

1. 홈 화면에서 오늘 현장을 확인합니다.
2. `출근` 버튼을 선택합니다.
3. 브라우저가 위치 권한을 요청하면 허용합니다.
4. 출근 완료 메시지를 확인합니다.
5. 출근 상태가 홈 화면에 표시되는지 확인합니다.

### 6.3 위치 권한이 안 될 때

| 기기 | 조치 |
|---|---|
| iPhone Safari | 설정 > Safari > 위치 또는 사이트 설정에서 허용 |
| Android Chrome | 주소창 자물쇠 아이콘 > 권한 > 위치 허용 |
| PWA 앱 | 휴대폰 앱 설정에서 위치 권한 허용 |

### 6.4 출근이 범위외로 표시될 때

가능한 원인:

- 실제 현장과 GPS 기준점이 다름
- 실내 또는 지하라 GPS가 흔들림
- 휴대폰 위치 정확도가 낮음
- 다른 현장을 선택함

조치:

1. 선택한 현장이 맞는지 확인합니다.
2. 위치가 안정될 때까지 잠시 기다립니다.
3. 그래도 범위외면 관리자에게 사유를 설명합니다.
4. 필요하면 출근부 수정 요청을 제출합니다.

---

## 7. 퇴근하기

### 7.1 퇴근 절차

1. 근무가 끝나면 홈 화면을 엽니다.
2. `퇴근` 버튼을 선택합니다.
3. 위치 권한이 필요하면 허용합니다.
4. 퇴근 완료 메시지를 확인합니다.
5. 오늘 출근부가 완료되었는지 확인합니다.

### 7.2 퇴근을 깜빡한 경우

퇴근을 누르지 못했으면 다음 중 하나가 필요할 수 있습니다.

- 늦은 퇴근 처리
- 출근부 수정 요청
- 관리자에게 사유 설명
- 관리자의 표준 퇴근시각 확정

주의:

- 퇴근 미실행 상태가 남아 있으면 급여 산정이나 문서 제출에 영향을 줄 수 있습니다.
- 반복적으로 퇴근을 누락하지 않도록 홈 알림을 확인합니다.

## 8. 근태 확인하기

관련 메뉴:

- 캘린더: `/worker/calendar`
- 근무 이력: `/worker/history`
- 출근부 검토: `/worker/review/attendance`

확인할 수 있는 내용:

- 날짜별 출근/퇴근 시간
- 지각/조퇴 여부
- 결근/미출근 표시
- 수정 요청 상태
- 월별 근무 현황

상태별 의미:

| 상태 | 의미 | 필요한 조치 |
|---|---|---|
| 정상 | 출퇴근이 정상 기록됨 | 없음 |
| 지각 | 기준시각보다 늦게 출근 | 사유 요청 시 답변 |
| 조퇴 | 기준시각보다 일찍 퇴근 | 사유 요청 시 답변 |
| 범위외 | GPS가 현장 밖으로 기록 | 사유 설명 |
| 퇴근 미실행 | 퇴근 기록 없음 | 수정 요청 또는 관리자 요청 확인 |
| 미출근 | 근무일인데 출근 기록 없음 | 실제 결근/휴무 여부 확인 |

---

## 9. 출근부 수정 요청

### 9.1 사용하는 경우

- 출근 버튼을 늦게 눌렀지만 실제 출근은 더 빨랐던 경우
- 퇴근 버튼을 깜빡했지만 실제 퇴근시간이 확인되는 경우
- GPS 오류로 잘못 기록된 경우
- 관리자가 시각 보정을 요청한 경우

### 9.2 요청 절차

1. 캘린더 또는 출근부 화면에서 수정할 날짜를 선택합니다.
2. 수정 요청 버튼을 선택합니다.
3. 수정할 출근/퇴근 시각을 입력합니다.
4. 사유를 구체적으로 작성합니다.
5. 제출합니다.
6. 관리자 승인/반려 결과를 기다립니다.

### 9.3 사유 작성 예시

좋은 예:

- “08:55 현장 도착 후 휴대폰 위치 권한 오류로 09:12에 출근 처리했습니다.”
- “18:00에 퇴근했으나 현장 정리 후 퇴근 버튼을 누르지 못했습니다.”
- “지하 주차장에서 GPS가 튀어 범위외로 기록되었습니다.”

좋지 않은 예:

- “수정해주세요.”
- “실수.”
- “몰라요.”

## 11. 업무일지 작성

관련 메뉴:

- 업무일지 작성: `/worker/worklog`
- 일괄 음성 일지: `/worker/worklog/batch`
- 일지 목록: `/worker/logs`
- 누락 일지: `/worker/logs/missing`
- 일지 검토: `/worker/review/logs`

### 11.1 작성 시점

일지는 가급적 근무 당일 퇴근 후 바로 작성합니다.

작성이 필요한 경우:

- 오늘 훈련생을 지도한 경우
- 누락 일지 목록에 표시된 경우
- 관리자 또는 위탁기관에서 보완 요청을 받은 경우

### 11.2 일반 일지 작성 절차

1. 업무일지 작성 화면으로 이동합니다.
2. 날짜와 훈련생을 확인합니다.
3. 훈련 유형을 확인합니다.
4. 지도시간과 근무시간을 확인합니다.
5. 수행 과업을 입력합니다.
6. 수행 평가 또는 점수를 입력합니다.
7. 지도 내용을 작성합니다.
8. 저장합니다.
9. 완료 상태를 확인합니다.

### 11.3 1:多 현장 작성 기준

한 명의 직무지도원이 여러 훈련생을 지도하는 현장에서는 훈련생별로 일지를 각각 작성해야 합니다.

예시:

- 오늘 담당 훈련생이 2명이라면 일지 2건 필요
- 1명만 작성하면 “미완료”로 남을 수 있음
- 관리자 문서 검토에서 누락으로 표시될 수 있음

### 11.4 AI 음성 일지 사용

사용 가능한 경우:

- 기관 플랜에서 AI 기능이 허용된 경우
- 브라우저에서 마이크 권한을 허용한 경우

절차:

1. 업무일지 작성 화면에서 음성 녹음을 시작합니다.
2. 오늘 지도한 내용을 말합니다.
3. 녹음을 종료합니다.
4. AI가 만든 초안을 확인합니다.
5. 틀린 내용, 과장된 내용, 빠진 내용을 수정합니다.
6. 저장합니다.

말하면 좋은 내용:

- 오늘 한 활동
- 훈련생 반응
- 수행 과업
- 지도한 내용
- 어려웠던 점
- 다음 지도 계획

주의:

- 주민등록번호, 진단명 등 불필요한 민감정보를 말하지 않습니다.
- AI 결과는 자동 확정이 아니므로 반드시 직접 확인합니다.
- 훈련생 이름과 음성 내용이 외부 AI 서비스로 처리될 수 있습니다.

### 11.5 일괄 음성 일지

사용하는 경우:

- 여러 날짜 또는 여러 훈련생 일지를 한 번에 초안 작성할 때
- 누락 일지가 많을 때

절차:

1. 일괄 음성 일지 화면으로 이동합니다.
2. 대상 기간과 훈련생 목록을 확인합니다.
3. 녹음합니다.
4. AI가 나눈 초안을 확인합니다.
5. 각 훈련생/날짜별 내용을 수정합니다.
6. 저장합니다.

## 12. 문서 생성과 제출

관련 메뉴:

- 문서: `/worker/docs`
- 문서 보기: `/worker/docs/view`
- 문서 미리보기: `/worker/docs/preview`
- 서명 관리: `/worker/signature`

### 12.1 문서 제출이 필요한 경우

- 월말 출근부 제출
- 훈련일지 제출
- 훈련생 종합평가 제출
- 적응지도 일지 제출
- 적응지도 종합평가 제출

### 12.2 제출 절차

1. 문서 메뉴로 이동합니다.
2. 제출할 기간을 선택합니다.
3. 제출할 문서 유형을 선택합니다.
4. 미리보기를 엽니다.
5. 내용이 맞는지 확인합니다.
6. 필수 서명을 확인합니다.
7. PDF를 생성합니다.
8. 제출합니다.
9. 제출 완료 상태를 확인합니다.

### 12.3 제출 전 확인표

| 확인 항목 | 설명 |
|---|---|
| 기간 | 제출 월 또는 기간이 맞는지 |
| 현장 | 오늘/해당 기간의 현장이 맞는지 |
| 출근부 | 출근/퇴근, 지각, 조퇴, 결근 표시가 맞는지 |
| 일지 | 훈련생별 일지가 모두 작성되었는지 |
| 평가 | 평가 점수와 의견이 작성되었는지 |
| 서명 | 직무지도원/사업체/관리자 서명 필요 여부 |

### 12.4 사업체 담당자 서명 받기

사용하는 경우:

- 출근부 또는 문서에 사업체 담당자 서명이 필요한 경우

절차:

1. 문서 화면에서 사업체 담당자 서명 링크를 발급합니다.
2. 담당자에게 링크를 전달합니다.
3. 담당자가 모바일에서 서명합니다.
4. 서명 완료 상태를 확인합니다.
5. 문서를 제출합니다.

주의:

- 서명 링크는 다른 사람에게 전달하지 않도록 안내합니다.
- 서명 링크는 만료될 수 있습니다.
- 담당자가 잘못 서명한 경우 관리자에게 문의합니다.

### 12.5 제출 후 변경 요청을 받은 경우

1. 알림 또는 문서 메뉴에서 변경 요청을 확인합니다.
2. 요청 사유를 읽습니다.
3. 일지, 출근부, 평가, 서명 중 필요한 부분을 수정합니다.
4. 문서를 다시 생성합니다.
5. 재제출합니다.

## 13. 계약서 서명

관련 경로:

- 계약서 링크: `/contract/[token]`
- 계약서 목록: `/worker/contracts`

### 13.1 계약서 서명 절차

1. 알림톡 또는 전달받은 링크를 엽니다.
2. 계약서 내용을 확인합니다.
3. 계약 기간을 확인합니다.
4. 근무장소와 근무형태를 확인합니다.
5. 임금과 지급 조건을 확인합니다.
6. 특약을 확인합니다.
7. 내용이 맞으면 서명합니다.
8. 제출합니다.
9. 서명 완료 메시지를 확인합니다.

### 13.2 서명 전 확인해야 할 것

- 이름이 맞는지
- 근무 현장이 맞는지
- 계약 시작일과 종료일이 맞는지
- 근무시간이 맞는지
- 급여 조건이 맞는지
- 휴게시간과 지도시간 조건이 맞는지
- 특약이 이해되는지

### 13.3 내용이 틀린 경우

서명하지 말고 위탁기관 관리자에게 문의합니다.

예:

- 현장이 다름
- 급여가 다름
- 계약 기간이 다름
- 근무시간이 다름
- 이름/전화번호가 다름

## 14. 급여명세서 확인

관련 메뉴:

- 급여: `/worker/payroll`

확인할 수 있는 내용:

- 월별 급여
- 근무일수
- 근무시간
- 기본급
- 주휴수당
- 공제 항목
- 실지급액
- 임금명세서 PDF

확인 절차:

2. 조회할 월을 선택합니다.
3. 급여 항목을 확인합니다.
4. 임금명세서를 열어 상세 내역을 확인합니다.

급여가 예상과 다를 때:

1. 출근부에 누락/보정대기가 있는지 확인합니다.
2. 수정 요청이 승인되었는지 확인합니다.
3. 휴무/결근 처리 여부를 확인합니다.
4. 위탁기관 관리자에게 문의합니다.

- 관리자 요청에 늦게 응답하면 문서 제출이나 급여 산정이 지연될 수 있습니다.

## 16. 프로필과 서명 관리

관련 메뉴:

- 프로필: `/worker/profile`
- 서명: `/worker/signature`
- 이메일 변경: 프로필 내 이메일 변경
- 자격/직종: `/worker/profile/professions`

### 16.1 프로필 수정

수정 가능한 항목은 기관 정책에 따라 다를 수 있습니다.

- 이름
- 전화번호
- 이메일
- 비밀번호
- 계좌정보
- 생년월일

개인정보 주의:

- 전화번호는 로그인과 알림에 사용될 수 있습니다.
- 계좌정보는 급여 지급에 영향을 줄 수 있습니다.
- 변경 후 관리자 확인이 필요할 수 있습니다.

### 16.2 서명 등록

절차:

1. 서명 메뉴로 이동합니다.
2. 서명패드에 직접 서명합니다.
3. 저장합니다.
4. 미리보기에서 서명이 올바르게 보이는지 확인합니다.

사용처:

- 출근부
- 문서 제출
- 계약서

## 17. 데이터 내보내기와 탈퇴

관련 메뉴:

- 데이터 내보내기: `/worker/export`
- 프로필 삭제/탈퇴: 프로필 메뉴

### 17.1 데이터 내보내기

본인의 근무 이력이나 관련 데이터를 내려받을 수 있습니다. 기관 정책과 기능 상태에 따라 제공 항목이 달라질 수 있습니다.

### 17.2 탈퇴

탈퇴 전 확인:

- 진행 중인 계약이 있는지
- 미제출 문서가 있는지
- 급여 정산이 남아 있는지
- 법정 보존 대상 문서가 있는지

주의:

- 탈퇴해도 법적으로 보존해야 하는 계약서, 출근부, 급여자료는 즉시 삭제되지 않을 수 있습니다.
- 개인정보 처리방침의 보존 기간을 확인하세요.

## 18. 자주 발생하는 문제

| 문제 | 해결 방법 |
|---|---|
| 위치 권한이 안 뜸 | 브라우저 설정에서 위치 권한 허용 |
| 출근 버튼이 안 보임 | 오늘 현장 선택, 배정 상태 확인 |
| 다른 현장으로 출근됨 | 현장 선택 화면에서 올바른 현장 선택 |
| 퇴근을 깜빡함 | 출근부 수정 요청 또는 관리자에게 문의 |
| 일지가 미완료로 남음 | 훈련생별 일지를 모두 작성했는지 확인 |
| AI 일지가 안 됨 | 마이크 권한, 기관 플랜, 네트워크 확인 |
| 문서 제출이 안 됨 | 누락 일지, 필수 서명, 기간 확인 |
| 계약 링크가 만료됨 | 위탁기관 관리자에게 재발급 요청 |
| 급여가 이상함 | 출근부 보정대기/수정 요청 상태 확인 |

8. 서명 등록 상태 확인
9. 사업체 담당자 서명 필요 여부 확인
10. 문서 미리보기 확인

13. 급여명세서 확인

## 20. 개인정보 보호 주의사항

직무지도원은 훈련생 정보와 현장 정보를 다루므로 다음을 지켜야 합니다.

- 훈련생의 장애정보, 보호자 연락처, 평가 내용을 외부에 공유하지 않습니다.
- 업무일지에 불필요한 민감정보를 적지 않습니다.
- AI 음성 녹음에 민감한 개인정보를 포함하지 않습니다.
- 서명 링크나 계약 링크를 다른 사람에게 전달하지 않습니다.
- 공용 기기에서 로그인한 경우 반드시 로그아웃합니다.
- 휴대폰을 분실하면 즉시 위탁기관 관리자에게 알립니다.
