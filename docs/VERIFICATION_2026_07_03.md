### 1-1. AI 음성 국외이전 **별도 동의** (커밋 b14b4a1)

**무엇을 했나**
음성 입력(원문 STT / AI 문장변환) 시 녹음·일지 맥락이 **Groq(미국)·Google Gemini(미국)** 로 전송되므로,
개인정보 **국외 이전에 대한 별도 동의**를 최초 1회 받고 기록하도록 함. 미동의 시 직접 입력(키보드)만 가능.
- DB: `Worker.consentAiCrossBorderAt`(동의 시각)
- API: `/api/worker/ai/consent` (조회 GET / 기록 POST·멱등·감사로그)
- 프론트 게이트: 녹음 시작 직전 동의 모달 / 서버 게이트: 미동의 시 STT 호출 전 403
- 개인정보처리방침에 **제5조의2(국외 이전)** 조항 추가

> ⚠️ AI 음성은 **근로계약 기간 중(유료 기능)인 직무지도원**에게만 버튼이 보입니다. 확인 시 해당 조건의 계정 필요.

**직접 확인할 것**
- [ ] **최초 동의 모달**: (아직 동의 안 한 직무지도원) 일지 작성 → 음성 FAB → 녹음 시작 → **"개인정보 국외 이전 동의"** 모달이 뜬다.
- [ ] **취소 시 중단**: 모달에서 취소 → 녹음이 시작되지 않는다.
- [ ] **동의 후 진행**: 체크박스 체크 → "동의하고 사용" → 바로 녹음 시작된다.
- [ ] **멱등(재요청 안 뜸)**: 앱 새로고침 후 다시 음성 시작 → 모달이 **다시 뜨지 않는다**(이미 동의 기록).
- [ ] **일괄 일지도 동일**: 일괄 일지(여러 훈련생) 녹음에서도 동일하게 게이트 동작.
- [ ] **문구/줄바꿈**: 안내문 "…외부 AI 서비스(해외 처리 포함)로 **전송 및 처리**됩니다." 다음 줄에 "자세한 내용은 개인정보처리방침을 확인 바랍니다."
- [ ] **모달 내 상세**: 동의 모달에 Groq/Google 각 국가·목적·보유기간(즉시 파기) 요약이 보인다.
- [ ] **(선택) 서버 이중방어**: 동의 철회 상태를 재현하기 어렵다면 생략 가능. 개발자 도구로 동의 전 `/api/worker/ai/voice-to-log` 직접 호출 시 403.

### 2-1. codex 출시 전 감사 A~G — P0/P1 7건 (배포 75cc4ec)

- [ ] **A. 출근부 현장 필터**: 매니저 출근부에서 **다른 현장 데이터가 섞여 보이지 않는지**(현장별로 정확히 필터).
- [ ] **B. 훈련생 IDOR(6곳)**: 특정 직무지도원/기관이 **권한 없는 훈련생 정보에 접근 불가**한지(URL의 훈련생 ID를 임의로 바꿔 접근 시 차단).
- [ ] **C. 감사로그 PII 마스킹**: 운영자 감사 화면(`/admin/audit`)에서 민감정보(주민/계좌 등)가 **마스킹**되어 보이는지.
- [ ] **D. 서명 토큰 race**: 동일 서명 링크를 **동시에 두 번** 열어도 이중 처리/오류 없이 안전한지.
- [ ] **E. 크론 비밀값 헤더**: 크론 엔드포인트가 **비밀 헤더 없이는 401/거부**되는지(외부에서 임의 호출 차단).
- [ ] **F. 급여 배정 ACTIVE 필터**: 급여 계산 대상이 **현재 활성 배정만** 잡히는지(과거 이탈자 미포함).
- [ ] **G. 급여 1:多 일자별**: 한 직무지도원이 **여러 현장/조합**일 때 급여가 현장·일자별로 정확히 분리 계산되는지.
