## AbleLink 관리자 UI 공통 가독성 규칙

주 사용자가 고령층이다. 모든 관리자 목록/상세 화면은 아래 규칙을 따른다.
"가독성 규칙 적용"이라는 지시를 받으면 이 섹션을 기준으로 작업한다.

### 글자
1. 목록(테이블/리스트) 본문 글자 크기는 모든 셀에서 동일하게 통일한다. (권장 본문 15px)
   특정 셀만 임의로 키우지 않는다. (예: '이름만 크게' 금지)
2. font-weight도 일관되게. 본문 셀은 전부 같은 weight(권장 500), 헤더 행만 한 단계 더 굵게(600).
   '이름만 bold' 같은 들쭉날쭉한 굵기 제거.
3. 폰트 컬러는 '의미'가 있는 곳에만 쓴다. 날짜·이름·현장·시간 같은 일반 본문은 연회색 대신
   고대비 진한 색 하나로 통일(near-black, 예: #1f2937). 장식성 회색 텍스트는 전부 진하게.
   색을 유지할 곳: 상태 뱃지, GPS 정상(초록)/이탈(빨강) 등 상태를 뜻하는 표시만.

### 뱃지
4. 상태 뱃지(근무중/종료/정상/활성/훈련중 등)는 크기와 글자 크기를 키운다.
   (글자 권장 13px, 상하·좌우 패딩 확대) 공용 컴포넌트면 그 컴포넌트에서 한 번만 키워
   전 화면이 일관되게 커지도록 한다.
   ※ 예외: '공지 카테고리(안내/주의/긴급)' 뱃지는 운영자가 색까지 직접 설정하는 별개 시스템이다.
     그 카테고리 뱃지 컴포넌트와 색상 설정 로직은 절대 건드리지 않는다.

### 클릭 영역
5. 조작 요소(뷰 전환 버튼, CSV·다운로드 버튼, 필터 칩, 이전/다음 페이지, 행 액션 버튼)의
   클릭 영역을 키운다. (권장 min-height 40px, 좌우 패딩 충분히)

### 반드시 지킬 것 (가드레일)
- 가독성 작업은 '순수 스타일'만 수정한다. 테이블 컬럼·데이터·조회/필터 로직은 변경 금지.
- 행 클릭 동작은 각 화면의 현재 상태를 그대로 유지한다. 원래 클릭 안 되는 화면에
  onClick·cursor:pointer·호버 이동을 새로 추가하지 않는다.
- 탭/뷰 전환 동작은 그대로 유지한다.
- 기존 파일의 스타일 작성 방식(인라인 스타일 / className 등)을 그대로 따른다.
- 작업 대상으로 지정한 화면(또는 공용 컴포넌트) 외에는 수정하지 않는다.
