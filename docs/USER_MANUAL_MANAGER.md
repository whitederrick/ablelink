# Able-Link 사용자 매뉴얼 - 위탁기관 관리자

문서 버전: v0.9 draft  
대상 사용자: 위탁기관 관리자  
작성 기준: 2026-07-03 현재 코드 기준  
주의: 현재 일부 기능은 개발/검증 진행 중입니다. 실제 운영 전 화면명과 버튼명은 최종 배포본 기준으로 한 번 더 확인해야 합니다.

---

## 1. 이 매뉴얼의 목적

이 문서는 위탁기관 관리자가 Able-Link에서 실제 업무를 처리하는 순서대로 따라갈 수 있도록 만든 매뉴얼입니다. 메뉴 설명이 아니라 “처음 기관을 세팅하고, 현장을 등록하고, 직무지도원을 배정하고, 매일 근태와 일지를 확인하고, 월말에 문서를 확정/발송하고, 급여를 산정하는 흐름”을 기준으로 작성했습니다.

위탁기관 관리자의 기본 업무 흐름은 다음과 같습니다.

1. 로그인 및 기관 기본정보 확인
2. 현장 등록
3. 훈련생과 담당자 정보 확인
4. 직무지도원 계정 준비
5. 직무지도원 현장 배정
6. 필요 시 근로계약서 발송
7. 일일 근태 확인
8. 업무일지 작성 현황 확인
9. 근태 이슈와 수정 요청 처리
10. 월말 문서 검토, 확정, 서명, 공단 발송
11. 급여 산정 및 임금명세서 확인
12. 공지, 알림, 지원 요청, 구독 관리

## 2. 로그인과 첫 화면 확인

### 2.1 접속 경로

- 로그인: `/manager/login`
- 로그인 후 첫 화면: `/manager`

### 2.2 로그인 절차

1. Able-Link 위탁기관 관리자 로그인 화면으로 이동합니다.
2. 관리자 ID와 비밀번호를 입력합니다.
3. 로그인을 선택합니다.
4. 로그인 후 통합 운영 대시보드로 이동합니다.

### 2.3 첫 화면에서 확인할 것

| 확인 항목 | 의미 | 조치 |
|---|---|---|
| 오늘 근태 현황 | 오늘 출근/퇴근 진행 상태 | 미출근, 지각, 퇴근 미실행 확인 |
| 근태 이슈 | 보정이나 사유 확인이 필요한 항목 | 근태 이슈 확인 메뉴에서 처리 |
| 문서 상태 | 직무지도원이 제출한 문서와 검토 필요 문서 | 문서 관리 메뉴에서 확인 |
| 공지/알림 | 운영자 공지, 기관 공지, 시스템 알림 | 필요한 내용 확인 |
| 구독 상태 | 사용 가능한 기능 범위 | 기능 제한 시 구독 메뉴 확인 |

### 2.4 로그인 문제 해결

| 문제 | 확인할 내용 |
|---|---|
| 로그인이 되지 않음 | ID/비밀번호 오입력, 계정 비활성화 여부 |
| 권한 없음 메시지 | 소속 기관 관리자 계정인지 확인 |
| 특정 메뉴가 잠김 | 구독 플랜 제한 가능성 확인 |
| 화면이 오래된 것 같음 | 브라우저 새로고침 또는 캐시 삭제 |

## 3. 기관 기본정보와 관리자 서명 설정

### 3.1 기관 기본정보 확인

메뉴:

- 기관 정보 관리: `/manager/settings`

확인 항목:

- 위탁기관명
- 사업자정보
- 대표자명
- 주소
- 대표 연락처
- 문서 발송용 이메일
- 공단 담당자 정보
- 사업체/현장 담당자 정보 정책

### 3.2 기관 정보 수정 절차

1. `운영관리 > 위탁기관 정보 관리` 메뉴로 이동합니다.
2. 기관 기본정보를 확인합니다.
3. 변경할 항목을 수정합니다.
4. 저장합니다.
5. 문서 미리보기 또는 계약서에 반영되는 정보가 맞는지 확인합니다.

### 3.3 관리자 서명 등록

메뉴:

- 관리자 서명 관리: `/manager/signature`

사용 시점:

- 문서 확정 후 위탁기관 관리자 서명을 적용할 때
- 공단 제출 문서에 기관 담당자 서명이 필요한 경우
- 계약서에 관리자 또는 대표자 서명이 필요한 경우

절차:

1. `운영관리 > 관리자 서명 관리` 메뉴로 이동합니다.
2. 서명패드에 본인 서명을 입력합니다.
3. 저장합니다.
4. 저장된 서명이 올바르게 표시되는지 확인합니다.

스마트폰으로 서명하는 경우:

1. PC에서 모바일 서명 토큰을 발급합니다.
2. 스마트폰으로 링크 또는 QR에 접속합니다.
3. 스마트폰 화면에서 서명합니다.
4. PC 화면에서 서명이 반영되었는지 확인합니다.

주의사항:

- 다른 사람의 서명을 대신 등록하지 않습니다.
- 대표자 서명은 계약서에 자동 적용될 수 있으므로 권한을 확인합니다.
- 서명 이미지는 법적 문서에 사용될 수 있으므로 테스트 서명을 운영에 남기지 않습니다.

## 4. 현장 등록과 관리

### 4.1 현장 등록 메뉴

- 현장 목록: `/manager/sites`
- 새 현장 등록: `/manager/sites/new`
- 현장 상세: `/manager/sites/[id]`

### 4.2 현장 등록 절차

1. `현장/인원 > 현장 관리` 메뉴로 이동합니다.
2. `새 현장 등록`을 선택합니다.
3. 사업체명과 주소를 입력합니다.
4. 주소 검색 결과로 GPS 좌표를 설정합니다.
5. 출퇴근 허용 반경을 입력합니다.
6. 근무형태를 설정합니다.
7. 출퇴근 지도 포함 여부를 설정합니다.
8. 지각 인정 기준이 필요하면 현장별 기준을 입력합니다.
9. 사업체 담당자와 공단 담당자 정보를 입력합니다.
10. 저장합니다.

### 4.3 현장 입력 항목 설명

| 항목 | 설명 | 영향을 주는 기능 |
|---|---|---|
| 사업체명 | 현장 이름 | 문서, 계약서, 근태 화면 |
| 주소 | 실제 근무지 주소 | 지도, GPS 기준점 |
| GPS 기준점 | 출퇴근 위치 판정 기준 | 정상/범위외 판정 |
| 허용 반경 | 정상 출퇴근 인정 거리 | 근태 이슈 |
| 근무형태 | 오전/오후/전일/커스텀 | 출퇴근 기준시각, 급여, 문서 |
| 커스텀 시간 | 직접 설정한 출퇴근 시간 | 근태, 급여, 문서 |
| 출퇴근 지도 포함 | 지도 시간이 근무시간에 포함되는지 | 일지/문서 시간 |
| 지각 인정 기준 | 몇 분 이상 늦으면 이슈인지 | 근태 이슈, 급여 보정대기 |
| 담당자 정보 | 사업체/공단 담당자 | 서명, 이메일 발송 |

### 4.4 저장 후 확인할 것

- 지도 위치가 실제 현장과 맞는지 확인합니다.
- 허용 반경이 너무 좁거나 넓지 않은지 확인합니다.
- 근무형태와 실제 근무시간이 맞는지 확인합니다.
- 문서 발송 대상 담당자 이메일이 맞는지 확인합니다.

### 4.5 현장 수정 시 주의사항

- GPS 기준점을 바꾸면 이후 출퇴근 판정에 영향을 줍니다.
- 근무시간을 바꾸면 지각/조퇴 판단과 급여 산정에 영향을 줍니다.
- 이미 생성된 출근부와 문서에는 기존 값이 남아 있을 수 있습니다.
- 월 중간에 변경한 경우 변경일 전후 기준을 별도로 확인합니다.

## 5. 훈련생 정보 확인과 배치

### 5.1 관련 메뉴

- 훈련생 현황 관리: `/manager/trainees`
- 현장 상세의 훈련생 탭: `/manager/sites/[id]`

### 5.2 확인할 항목

| 항목 | 설명 |
|---|---|
| 훈련생 이름 | 일지/평가 문서에 표시 |
| 현장 | 현재 소속 현장 |
| 배치 시작일 | 일지/출근부 1:1/1:多 기준 |
| 배치 종료일 | 이탈/종료 후 과거 문서 재생성 기준 |
| 상태 | 훈련 중, 이탈, 중지 등 |
| 장애/보호자 정보 | 개인정보 보호 주의 |

### 5.3 운영 기준

- 훈련생 배치 기간은 일지 완료 기준과 출근부 1:1/1:多 판정에 영향을 줍니다.
- 월 중간에 훈련생이 추가되거나 이탈하면 문서와 급여가 일자별로 달라질 수 있습니다.
- 훈련생 정보는 개인정보와 민감한 배경정보를 포함할 수 있으므로 불필요하게 공유하지 않습니다.

## 6. 직무지도원 계정 관리

### 6.1 관련 메뉴

- 직무지도원 관리: `/manager/worker-accounts`
- 직무지도원 배정 관리: `/manager/workers`

### 6.2 신규 직무지도원 준비 방법

가능한 방식:

1. 관리자가 직무지도원 계정을 직접 생성합니다.
2. 기존 직무지도원을 검색하여 배정합니다.
3. 계약서 발송 과정에서 임시 계정을 생성합니다.
4. 초대 링크 또는 연결 인증코드로 가입/연결합니다.

### 6.3 계정 생성/확인 시 입력 항목

| 항목 | 설명 | 주의 |
|---|---|---|
| 이름 | 직무지도원 실명 | 문서/급여명세서에 표시 |
| 전화번호 | 로그인 ID로 쓰일 수 있음 | 중복 확인 |
| 임시 비밀번호 | 최초 로그인 또는 재설정 | 안전하게 전달 |
| 상태 | 활성/비활성 | 비활성 계정은 로그인 불가 |
| 계좌정보 | 급여 지급용 | 개인정보 |
| 생년월일 | 임금명세서 등 문서용 | 개인정보 |

### 6.4 비밀번호 초기화

1. 직무지도원 상세를 엽니다.
2. 비밀번호 초기화를 선택합니다.
3. 임시 비밀번호를 발급합니다.
4. 직무지도원에게 안전한 방법으로 전달합니다.
5. 직무지도원이 로그인 후 비밀번호를 변경하도록 안내합니다.

주의:

- 임시 비밀번호를 메신저 단체방에 공유하지 않습니다.
- 임시 비밀번호 화면을 캡처하여 오래 보관하지 않습니다.
- 전달 후 비밀번호 변경 여부를 확인합니다.

## 7. 직무지도원 현장 배정

### 7.1 관련 메뉴

- 직무지도원 배정 관리: `/manager/workers`
- 직무지도원 배정 확정: `/manager/assignment-selection`

### 7.2 배정 생성 절차

1. 배정할 직무지도원을 선택합니다.
2. 배정할 현장을 선택합니다.
3. 배정 시작일과 종료일을 입력합니다.
4. 근무형태와 근무시간을 확인합니다.
5. 출퇴근 버튼 면제 여부를 선택합니다.
6. 계약서 연결이 필요한 경우 계약과 연결합니다.
7. 저장합니다.

### 7.3 배정 상태 이해

| 상태 | 의미 | 관리자 조치 |
|---|---|---|
| ASSIGNED | 배정 생성 또는 요청됨 | 계약/연결 상태 확인 |
| CONFIRMED | 사전 조건이 확인됨 | 활성 전환 여부 확인 |
| ACTIVE | 실제 근무 중 | 근태/일지/문서 대상 |
| PAUSED | 일시 중지 | 급여/문서 포함 여부 확인 |
| DROPOUT | 이탈 또는 종료 | 과거 기간 문서/급여 재계산 주의 |

### 7.4 멀티현장 배정 주의

직무지도원이 여러 현장에 배정될 수 있습니다. 이 경우 다음을 확인합니다.

- 각 현장의 근무시간이 겹치지 않는지
- 직무지도원이 앱에서 오늘 근무 현장을 정확히 선택하는지
- 오전/오후 다른 현장 근무 시 출근부와 급여가 현장별로 나뉘는지
- 문서 생성 시 다른 현장 기록이 섞이지 않는지

## 8. 근로계약서 발송과 서명

### 8.1 관련 메뉴

- 근로계약서 관리: `/manager/contracts`
- 직무지도원 계약 서명 페이지: `/contract/[token]`

### 8.2 계약서 생성 절차

1. `현장/인원 > 근로계약서 관리` 메뉴로 이동합니다.
2. 새 계약서를 생성합니다.
3. 직무지도원을 선택합니다.
4. 연결할 현장 또는 배정을 선택합니다.
5. 계약 기간을 입력합니다.
6. 근무장소, 근무형태, 근무시간을 입력합니다.
7. 임금과 지급 조건을 입력합니다.
8. 필요한 특약을 입력합니다.
9. 계약서를 저장하고 서명 링크를 발송합니다.

### 8.3 직무지도원 서명 후 확인

직무지도원이 링크에서 서명하면 관리자는 다음을 확인합니다.

- 계약 상태가 서명 완료로 바뀌었는지
- 배정 상태가 정상적으로 연결되었는지
- 신규 직무지도원에게 임시 비밀번호 또는 가입 안내가 전달되었는지
- 기존 직무지도원에게 배정 연결 인증코드가 발송되었는지
- PDF 다운로드가 가능한지

### 8.4 계약서 오류 대응

| 문제 | 조치 |
|---|---|
| 계약 내용 오입력 | 계약 취소 후 재발행 또는 수정 정책 확인 |
| 서명 링크 만료 | 새 링크 발급 |
| 직무지도원이 다른 조건이라고 주장 | 서명 전 수정 후 재발송 |
| 배정 연결 실패 | 배정 상태와 인증코드 발송 여부 확인 |

## 9. 일일 근태 확인

### 9.1 관련 메뉴

- 근태 현황: `/manager/attendances`
- 근태 캘린더: `/manager/calendar`
- 근태 이슈 확인: `/manager/inbox/attendance`

### 9.2 매일 확인할 순서

1. 근태 현황에서 오늘 날짜를 선택합니다.
2. 현장별 출근자와 미출근자를 확인합니다.
3. 지각, 조퇴, 범위외 출근을 확인합니다.
4. 퇴근 시간이 지나도 퇴근하지 않은 건을 확인합니다.
5. 근태 이슈 확인 메뉴에서 처리 필요 항목을 확인합니다.

### 9.3 근태 이슈별 처리

| 이슈 | 설명 | 처리 |
|---|---|---|
| 지각 | 기준 출근시각보다 늦음 | 사유 확인 또는 보정 요청 |
| 조퇴 | 기준 퇴근시각보다 빠름 | 사유 확인 |
| GPS 범위외 | 허용 반경 밖에서 출퇴근 | 현장 위치/사유 확인 |
| 퇴근 미실행 | 출근 후 퇴근 기록 없음 | 직무지도원에게 퇴근 보정 요청 |
| 미출근 | 근무일인데 출근 기록 없음 | 결근 여부 확인 |

### 9.4 관리자 확정이 필요한 경우

다음과 같은 경우 관리자가 직접 처리할 수 있습니다.

- 직무지도원이 퇴근을 끝내 처리하지 않은 경우
- 현장 상황상 표준 퇴근시각으로 확정해야 하는 경우
- 급여 산정 전 보정대기 상태를 해소해야 하는 경우

주의:

- 관리자 확정은 급여에 영향을 줄 수 있으므로 사유를 확인합니다.
- 반복적으로 퇴근 미실행이 발생하면 직무지도원에게 사용법을 재안내합니다.

## 10. 출근부 수정 요청 처리

### 10.1 관련 메뉴

- 출근부 수정 요청 관리: `/manager/attendance-edit-requests`

### 10.2 처리 절차

1. 수정 요청 목록을 확인합니다.
2. 요청자, 날짜, 현장, 기존 시각, 요청 시각을 확인합니다.
3. 요청 사유를 읽습니다.
4. 필요한 경우 직무지도원에게 추가 확인합니다.
5. 승인 또는 반려를 선택합니다.
6. 처리 결과가 근태 기록에 반영되었는지 확인합니다.

### 10.3 승인 기준

승인 가능한 예:

- GPS 오류 또는 휴대폰 문제로 실제 출근시각과 다르게 기록된 경우
- 관리자가 확인한 현장 사정이 있는 경우
- 퇴근 누락 후 실제 근무 종료시각이 확인되는 경우

반려 가능한 예:

- 사유가 불명확한 경우
- 실제 근무 사실이 확인되지 않는 경우
- 급여를 부당하게 늘리려는 요청으로 보이는 경우

## 11. 업무일지 확인

### 11.1 관련 메뉴

- 훈련 일지 열람: `/manager/logs`
- 훈련생 진척 리포트: `/manager/reports`

### 11.2 확인 절차

1. 일지 열람 메뉴에서 기간을 선택합니다.
2. 직무지도원 또는 현장으로 필터링합니다.
3. 훈련생별 일지 작성 여부를 확인합니다.
4. 미완료 일지가 있으면 직무지도원에게 보완을 요청합니다.
5. 리포트 메뉴에서 훈련생별 진척과 평가를 확인합니다.

### 11.3 완료 기준

| 현장 형태 | 완료 기준 |
|---|---|
| 1:1 | 해당일 담당 훈련생 일지 1건 완료 |
| 1:多 | 해당일 배치된 훈련생 수만큼 일지 완료 |
| 적응지도 | ADAPTATION 유형 일지 완료 |
| 평가 문서 대상 | 해당 평가 유형의 평가 작성 완료 |

주의:

- 직무지도원이 한 명만 작성했다고 해서 1:多 현장이 완료되는 것은 아닙니다.
- 월말 문서 제출 전 누락 일지를 먼저 정리해야 합니다.

## 12. 문서 검토, 확정, 서명, 공단 발송

### 12.1 관련 메뉴

- 문서 관리: `/manager/documents`
- 공단 제출 이력 관리: `/manager/gov-submissions`
- 문서 조회: `/manager/docs`
- 관리자 서명 관리: `/manager/signature`

### 12.2 문서 처리 전체 흐름

1. 직무지도원이 문서를 제출합니다.
2. 관리자는 문서 관리 메뉴에서 제출 문서를 확인합니다.
3. PDF 미리보기를 열어 내용을 검토합니다.
4. 오류가 있으면 변경 요청을 보냅니다.
5. 문제가 없으면 확정합니다.
6. 관리자 서명을 적용합니다.
7. 공단 담당자에게 발송합니다.
8. 공단 제출 이력에서 발송 내역을 확인합니다.

### 12.3 문서별 확인 기준

| 문서 | 확인할 내용 |
|---|---|
| 출근부 | 기간, 현장, 출퇴근 시각, 결근/지각/조퇴, 1:1/1:多, 서명 |
| 지원고용 훈련일지 | 훈련생, 날짜, PRE/FIELD, 과업, 평가, 지도시간 |
| 훈련생 종합 평가 | 점수, 의견, 기간, 훈련생 정보 |
| 적응지도 일지 | ADAPTATION 일지, 기간, 지도 내용 |
| 적응지도 종합 평가 | 점수, 의견, 적응지도 기간 |

### 12.4 변경 요청이 필요한 경우

- 출근부에 다른 현장 기록이 섞인 경우
- 훈련생 이름 또는 현장이 잘못된 경우
- 일지가 누락된 경우
- 서명이 누락된 경우
- 기간이 잘못된 경우
- 지각/결근 사유가 누락된 경우
- 평가 점수 또는 의견이 비어 있는 경우

### 12.5 공단 발송 전 체크리스트

- [ ] 관리자 서명 등록 완료
- [ ] 직무지도원 필수 서명 완료
- [ ] 사업체 담당자 필수 서명 완료
- [ ] 문서 기간 확인
- [ ] 현장 확인
- [ ] 훈련생 확인
- [ ] 누락 일지 없음
- [ ] 미처리 근태 이슈 없음
- [ ] 수신 담당자 이메일 확인

## 13. 급여 산정

### 13.1 관련 메뉴

### 13.2 급여계약 등록

1. 급여 관리 메뉴로 이동합니다.
2. 직무지도원을 선택합니다.
3. 급여유형을 선택합니다.

5. 1:多 단가가 있으면 입력합니다.
6. 소득유형을 설정합니다.
7. 보험/공제 정책을 설정합니다.
8. 저장합니다.

### 13.3 월별 급여 run 생성 전 확인

- 해당 월 근태가 정리되었는지
- 보정대기 건이 남아 있지 않은지
- 출근부 수정 요청이 모두 처리되었는지
- 월중 입사/퇴사/배정 종료가 반영되었는지
- 훈련생 수 변경이 반영되는지
- 공휴일/커스텀휴무가 등록되어 있는지
- 급여계약이 유효한지

### 13.4 급여 결과 검토

- 근무일수
- 근무시간
- 기본급
- 주휴수당
- 연장/야간/휴일 가산
- 소득세/지방소득세
- 4대보험
- 기타 공제
- 실지급액

주의:

- 급여 확정 전 반드시 샘플 직무지도원 몇 명을 수기로 대조합니다.
- 노무사 확인 전 정책 보류 항목은 자동 확정하지 않습니다.
- 월중 훈련생 수 변동이나 멀티현장 근무는 특히 주의합니다.

## 18. 자주 발생하는 문제

| 문제 | 원인 | 해결 |
|---|---|---|
| 직무지도원이 출근 버튼을 못 누름 | 현장 선택 안 됨, 배정 비활성, 위치권한 거부 | 배정 상태와 위치권한 확인 |
| 출근이 범위외로 뜸 | GPS 기준점 오류, 현장 반경이 좁음 | 현장 지도 기준점 확인 |
| 일지가 완료로 안 뜸 | 1:多 훈련생 중 일부 누락 | 훈련생별 일지 확인 |
| 문서 발송이 안 됨 | 필수 서명 누락 | 직무지도원/사업체/관리자 서명 확인 |
| 급여가 예상과 다름 | 보정대기 제외, 단가 오류, 휴일 정책 차이 | 출근부와 급여계약 대조 |
| 알림톡이 안 감 | 템플릿 코드/env 미설정 | 운영자에게 환경변수 확인 요청 |
| PDF에 서명이 안 나옴 | 서명 저장/URL 문제 | 서명 재등록 후 미리보기 |

## 19. 개인정보 취급 주의사항

위탁기관 관리자는 다음 정보를 볼 수 있으므로 주의해야 합니다.

- 직무지도원 이름, 전화번호, 생년월일
- 계좌정보
- GPS 출퇴근 위치
- 서명 이미지
- 훈련생 이름, 장애유형, 보호자 연락처
- 업무일지와 평가 내용
- 계약서와 급여명세서

운영 원칙:

- 업무 목적 외 조회 금지
- 화면 캡처 공유 최소화
- 외부 전송 전 개인정보 마스킹
- 첨부파일 보관 기간 최소화
- 퇴사자/담당자 변경 시 계정 비활성화 요청
