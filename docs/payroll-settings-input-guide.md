# 급여 설정값 입력 가이드 (4대보험 요율 · 간이세액표)

> 이 두 값이 **비어 있으면 급여명세서의 4대보험·소득세가 전부 0원으로 계산**됩니다.
> 시드/코드에 박지 않고 **운영자가 매년 직접 입력**하도록 설계돼 있습니다(정부가 매년 갱신하므로).
> 2026-07-02 기준 **운영(prod)·dev 양쪽 다 미입력** — 실사용 전 반드시 입력하세요.

---

## 1. 4대보험 요율

**경로:** 운영자 로그인 → 설정 → **4대보험 요율** (`/admin/settings/insurance-rates`)

**입력 방법:** `연도` 입력 → 각 칸에 **% 단위**로 입력(예: `4.5`) → 저장. (기존 연도 행을 클릭하면 프리필됨)

**적용 방식:** 각 요율은 `과세급여(gross) × 요율`로 워커 공제. 가입유형(일용/초단시간/일반)에 따라 해당 보험만 자동 공제. **산재는 워커 공제 제외(전액 사업주, 표기용)**.

### 입력값 (2025년 근로자 부담 기준 — ⚠️ 해당 연도 공식 고시값으로 반드시 확인)

| 항목 | 입력값(%) | 비고 |
|---|---|---|
| 국민연금 | `4.5` | 근로자 부담(총 9%의 절반) |
| 건강보험 | `3.545` | 근로자 부담(총 7.09%의 절반) |
| 장기요양 | `0.4591` | **⚠️ 함정 주의** — 아래 설명 |
| 고용보험 | `0.9` | 근로자 부담(실업급여분) |
| 산재(사업주) | `0.7` 등 | 업종별 상이. 워커 공제 아님(선택 입력) |

#### ⚠️ 장기요양보험 입력 함정
- **실제 법령**: 장기요양보험료 = 건강보험료 × 12.95%(2025) — 즉 "건강보험료"에 곱하는 값.
- **이 시스템**: `과세급여 × 장기요양요율`로 계산(건강보험료가 아니라 과세급여 기준).
- **따라서** 과세급여 기준 실효율을 넣어야 함 = `3.545% × 12.95% ≈ 0.4591%` → 칸에 **`0.4591`** 입력.
- ❌ `12.95`를 넣으면 안 됨(그러면 과세급여의 12.95%가 장기요양으로 잡혀 폭증).

#### 알아둘 한계(근사)
- 국민연금 **기준소득월액 상·하한**(상한/하한 등급) 미반영 → `과세급여 × 4.5%` 단순 계산. 고소득·저소득 경계는 근사값(대부분 직무지도원 급여대에선 무방).
- 근본 정확화(표준소득월액 등급표 도입)는 백로그.

## 2. 근로소득 간이세액표

**경로:** 운영자 로그인 → 설정 → **근로소득 간이세액표** (`/admin/settings/income-tax`)

**입력 방법:** `연도` 입력 → **홈택스에서 받은 엑셀(.xlsx) 원본을 그대로 업로드** → 자동 등록.
- 파일에 '간이세액표' 시트 + **'별표2'(8~20세 자녀 세액공제)** 시트가 함께 있어야 함(홈택스 원본이면 포함).
- 별표2를 인식 못 하면 **등록 거부** → 반드시 홈택스 원본 파일 그대로 업로드.
- 여러 시트가 있어도 세액표 시트를 자동 탐지.

**엑셀 다운로드 위치:**
- 국세청 홈택스 → 세금신고 자료·간이세액표, 또는 국세청 누리집 검색 "근로소득 간이세액표" → 엑셀(.xlsx) 다운로드.

**적용 방식:** 급여계산 시 `월 과세급여 + 공제대상가족수`로 세액 자동 조회. **주민세 = 소득세의 10%** 자동 계산. 8~20세 자녀공제는 별표2에서 자동 반영.

**업로드 후 검증:** 화면에 `구간수 · 급여범위 · 가족열 · 자녀공제` 요약이 뜸.
- **"✓ 검증 통과"** = 정상.
- "⚠ 확인 필요"(구간수 100 미만/순서 이상/가족열<11/자녀공제 미인식)면 파일을 다시 확인.

---

## 3. 입력 후 확인

- 임의 워커의 해당 월 급여를 계산(운영자 급여 실행)해서 **국민연금·건강·장기요양·고용·소득세·주민세 공제 라인이 잡히는지** 확인.
- 가입유형이 '일용/초단시간'이면 일부 보험만 잡히는 게 정상.
- **매년 초 새 연도 요율·세액표를 다시 입력**해야 함(연도별 저장).
