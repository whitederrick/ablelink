## 노무사 판정 7건 처리 결과

### #1 1개월 미만 조기퇴사자 국민연금·건강 (`42934fb`)
- **판정**: "근속<30일 무조건 0" 하드코딩 금지. 계약조건대로 정상 산출하되, 급여 확정 단계에서 관리자 '당월 예외' 체크로 공제 0 덮어쓰기. 사후정산은 공단 EDI 결과로 관리자 통제.
- **구현**: 급여 확정 화면 공제내역에 **'당월 예외' 버튼** — 클릭 시 국민연금·건강보험·장기요양보험 공제를 0으로(고용·산재 유지). `basicInfo.earlyLeaveExempt`로 보존. opt-in 순수 추가(미클릭 시 동작 불변). 수동 편집 PATCH에 **감사로그** 추가(노동청 분쟁 증빙).
- **사용자 확정 범위**: 국민연금 + 건강 + 장기요양(고용·산재 제외).

### #2 단시간 월급제 209h 통상시급 (`c8f9d25`)
- **판정**: 월급÷209 고정은 주40h 전용이라 단시간에 위법. (주 소정 + 주휴)×4.345로 동적 역산. 주20h → (20+4)×4.345 ≈ 104h.
- **구현**: `lib/payroll/ordinaryHours.ts` `monthlyStandardHours(weeklySojeHours)` — 주40h→209(관행값 정확 일치·무회귀 앵커), 단시간 비례 축소. 소정 상한 40h. 계약 시각 없으면 209 폴백.
- **실증**: 월120만·주16.5h 워커 연장수당 34,452 → 83,718원 정정. 전일제 무회귀.

### #3 주휴 개근 — 지각/조퇴는 결근 아님 (`d147dae`)
- **판정**: 개근 = 결근하지 않은 것. 지각·조퇴는 결근 아님 → 개근 인정. 무급차감만 가능, 주휴 박탈 금지(임금체불 리스크).
- **검증 결과 실제 갭**: 심한 지각/조퇴(≥30분, 보정 대기)일이 `confirmedAtt`에서 빠져 주휴 산정 days에서 제외 → 개근 실패 → 주휴 박탈.
- **구현**: computeRun 주휴 days를 '출근 기록 존재'(attendances + lookbackAtt 전체, 보정대기 포함)로 판정. 급여 **금액**은 여전히 confirmedAtt 게이트(우회 아님). 주휴액은 계약 소정근로시간 기반이라 지각일 짧은 실근로에 오염 안 됨.
- **실증**: 수요일 지각 → 주휴 0 → 48,000원 복원.

### #4 같은날 2배정 주휴 '1일 소정근로시간' (`d147dae`)
- **판정**: 동일 사업장은 근기법상 하나의 근로계약. (1주 총 소정 / 40) × 8 일괄 비례(하루평균 X).
- **검증 결과 실제 갭**: `weeklyHoliday`가 소정을 행별로 평균내 하루 2배정(AM+PM) 워커의 1주 소정을 절반으로 과소산정 → 주휴 과소지급.
- **구현**: dateISO 그룹으로 하루 소정 합산 후 평균(1주 총소정 기준). 단일배정 무회귀. 40h 상한 클램프가 합산 과다 방어.

### #5 개근월 1일 수당(P1-13) — workaround 완비 (`f1ec2a1`)
- **판정**: 맥락상 1년 미만 근로자 월 개근 시 연차 1일. 정식 연차 모듈 전까지 마지막 달/퇴직 정산에 1회성 수당으로 얹어 지급·명칭 명시. 연차미사용수당 = 100% 과세 근로소득.
- **결정(사용자)**: 정식 연차관리 모듈은 별도 세션. 그 전까지 **기존 급여 확정 그리드 '+ 항목'으로 "연차미사용수당" 자율 입력**(이미 구현·명세서 표기). 세금은 총액 기준.
- **리스크 제거(`f1ec2a1`)**: 과세 지급 라인 추가 시 소득세 미갱신으로 원천징수 오류가 나던 것 → **저장 시 소득세·주민세를 과세총액으로 자동 재계산**(상여 있으면 제외·간이세액표 미등록 시 수동값 유지). 국민연금·건강·장기요양은 기준소득월액/연말정산 기준이라 일시 수당으로 월 보험료 불변(정상), 고용보험만 실보수 — 화면 안내 추가.
- **참고(수기)**: 단시간 1일 소정 = (4주 총 소정 / 4주 통상근로일수) 비례. 퇴사 14일 내 지급.

### #6 프리랜서 근로기준법 가산 (`c8f9d25` + `d6380ad`)
- **판정**: 절대 자동 적용 금지(자동 가산 = 근로자성 자백). 완전 바이패스. 야간 보상은 가산율 곱하지 말고 계약 시 '야간 작업 단가' 필드 수기 입력.
- **구현(바이패스, `c8f9d25`)**: 연장/야간/휴일/주휴 가산을 `gateIncomeType==="EMPLOYMENT"` 게이트로 통일(종전 연장·야간·휴일 미게이트). 근로계약 있으면 항상 EMPLOYMENT → 정상 케이스 불변.
- **구현(야간단가, `d6380ad`)**: `PayContract.nightRate`(DECIMAL nullable) 수기 참조 필드. 급여 기준 폼에서 소득유형=사업소득일 때만 노출 + 안내. 목록에 '야간 N원/h' 표시. **급여엔진 미사용(참조·기록 전용)** — 급여 확정 시 지급내역에 수기 반영. 마이그 `20260714140000` 운영 선적용.

### #7 휴일근로 + 8h 초과 배수 — 기존 정확(무변경)
- **판정**: 근기법 §56② — 8h 이내 휴일근로 150%, 8h 초과 200%.

## 근무요일 필드 (비연속 근무 급여) — Phase 1 완결 (`3ddb16c`, `f0275c1`)

- **문제**: MWF/TTh 등 비연속 근무를 계약이 표현하지 못해 주휴·MONTHLY 일할이 과소지급(예: MWF 워커 주휴 0).
- **코어**: `lib/payroll/weekdays`(0=일..6=토 단일 소스 — parse/derive/resolve/validate). `deriveWorkingWeekdays`가 기존 computeRun 인라인 로직과 바이트 동치임을 테스트로 고정(무회귀 앵커). `EmploymentContract.workingWeekdays`(CSV) 필드. computeRun이 소정일수·MONTHLY 일할·주휴 개근에 이 Set 공유.
- **완결**: admin/contracts POST가 근무요일 수용·검증(0~6·주휴일 미포함), 집합 authoritative → workDaysPerWeek 정합. [id] GET이 편집 프리셀렉트용 `workingWeekdaysResolved` 반환. 계약 폼에 opt-in 요일 체크박스(미선택=기존 파생, 동작 불변).
- **실증**: MWF 워커 파생=주휴 0(과소) / 명시="1,3,5"=57,600원(수정).

## 건강보험 8일 트랙 제거 (`a2a985a`)

- **문제**: 계약 1개월 이상 워커의 4대보험을 단일 tier(월 60h **또는** 8일)로 뭉쳐 판정 → 주2~3일 단시간(8일↑·60h 미만)에게 건강+장기요양 과다부과.
- **구현**: 보험별 법정 기준 개별 적용 — 국민연금(60h OR 8일), **건강·장기요양(60h만)**, 고용(60h OR 계속근로 3개월), 산재(항상). tier 게이트(60h||8일) 불변 → 배지 무회귀. 실제 공제는 workerDeductible이 구동.
- **실증**: 단시간 8일·60h 미만 워커 건강+장기요양 약 32,000원/월 과다공제 방지, 국민연금만 정상 공제.
