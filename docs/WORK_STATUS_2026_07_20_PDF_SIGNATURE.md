### 1) 출근부 서명부 분할 — `3792360`
- **증상**: ①(흔함) 지도기간이 월~일 기준 6~7주에 걸치는 달이면 확인문구("위와 같이 근무하였음을 확인함")+작성일은 앞 페이지 하단에 남고 서명 3줄만 다음 페이지로 분리. ②(캐스케이드) 주차 그리드가 페이지 하단 특정 구간에서 끝나면 확인문구/작성일/서명이 각각 다른 3개 페이지로 흩어짐(사용자 목격 패턴, 스윕 114~126일 구간에서 재현).
- **원인**: 페이지가드가 `signatures()` 내부에만 있고 확인문구·작성일(`lib/pdf/pdfkitRenderer.ts` 282행 부근)은 무가드 → pdfkit 자동 흘림 + 수동 y좌표 desync.
- **수정**: 확인문구 직전에 블록 전체 높이(문구+작성일+서명 3줄 ≈161pt) 기준 가드 → 안 들어가면 블록 통째 다음 페이지.
- **검증**: 스윕 519케이스 분할 잔존 0건(전 케이스 확인문구·작성일·서명 동일 페이지). 기존 캐스케이드 케이스(120일): 5p 흩어짐 → 3p 블록 온전 배치.

### 2) 종합평가 평가소견 장문 붕괴 — `1aa4773` + `61bdfc7`
- **증상**: 소견 입력이 항목당 무제한(JSON 20k 상한뿐) → 약 1,500자부터 소견 셀이 6pt 축소 후에도 넘쳐 자동 흘림으로 1페이지 고정 레이아웃 붕괴.
- **수정 2층**:
  - 입력단: 항목당 **230자 상한** (API 400 메시지 + 워커 훈련/적응 평가화면 textarea `maxLength`). 230자 = 꽉 채워도 **8pt 이상 보장**(고령 가독성 지침, 사용자 결정).
  - 렌더러 최후 안전망: `cell()`이 6pt 하한까지 줄여도 넘치면 셀 높이로 클램프(`height`+`ellipsis` "…") — 레거시 장문 데이터·타 경로 포함 모든 고정높이 셀의 셀 밖 침범·페이지 붕괴 원천 차단.
- **검증**: 소견 100/230/400/1,500/5,000자 × 평가 2종 전부 1페이지 유지, 230자=8pt 렌더 실측.
- **소견 셀 수용량 실측**(참고): 9pt→187자 · 8pt→238자 · 7pt→296자 · 6pt→409자.
